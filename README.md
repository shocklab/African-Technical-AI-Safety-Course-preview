# African Technical AI Safety

Public course site: https://shocklab.github.io/African-Technical-AI-Safety-Course/

The 2026 taught route covers Sessions 1–9, then 11–13, followed by a research project. Session 10 is skipped. The numbers follow the original 24-session planning documents, which remain in this repository for reference. The [course contents](docs/index.html) and [route page](docs/short-course-2026.html) describe what is taught.

The site is served from `docs/` on `main`. `RELEASED-SESSIONS` lists the published numbered sessions. The project launch page is published separately.
